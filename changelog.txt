v0.3.3 - 2026-10-21

- metric_grid 每项新增可选十六进制 color，设置数值与强调线，保留主题背景。
- 新增 svg 叶区块，通过 DOMPurify 清洗和静态白名单后使用浏览器原生 SVG 渲染，支持基础形状、文字、渐变、裁剪和箭头标记。
- 限制节点、深度、大小与数值，隔离本图 ID 和引用，拒绝脚本、事件、外部资源、任意 CSS、动画及过滤器；未通过校验时恢复原始代码块。
- 限制箭头属性放置位置，禁止资源内再次引用箭头或裁剪，阻止继承和无环嵌套放大绘制量；补充标量及路径参数检查。
- 更新实际启用提示词、完整 SVG 示例、协议及三语说明，并增加清洗边界和浏览器回归。

- function_plot 新增可选 latex 字段，本地排版分式、根式和上下标等函数定义；数值求值仍使用原有受限表达式。
- 使用 KaTeX 生成原生 MathML，不加载外部字体或新增扩展权限；不支持或非法的 TeX 回退普通公式，保留曲线及滑块。
- 更新模型格式说明、协议、三语 README 及公式回归测试。
- 启用说明的主要 function_plot 字段模板直接列出 latex，并提供经实际扩展验证的完整 JSON 示例。

v0.3.1 - 2026-10-20

- 版本号更新为 0.3.1；协议仍为 DSUI v1，不改变既有功能与权限边界。
- 显式声明现有 d3-scale 及类型依赖，修复表格缺失单元格的原型属性读取和排序。
- 启用 UI 仅识别唯一、可见且具备发送语义的控件，拒绝通用 submit 兜底、冲突的停止/反馈等标识（含 data-testid）与隐藏祖先（含 content-visibility）。
- 拒绝误导性 Unicode 控制字符，保留正常多语言文字、emoji 连接符及完整合法的地区旗帜 tag 序列。
- 弹窗版本改为读取 manifest；关闭 modulepreload polyfill，扩展页面禁止网络连接。
- 所有构建 JS 增加动态代码和网络能力检查（含计算属性/别名计时器、内建函数派生 constructor、document.defaultView 别名）；禁用 Zod JIT，新增负对照与源码哈希验证。
- CI 增加全部生产依赖公告扫描，补充模型数据提示、安全报告说明及未解决许可证来源差异入口。
