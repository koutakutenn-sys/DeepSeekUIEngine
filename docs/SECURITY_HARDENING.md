# v0.3 后续安全加固

## 审计事项处理

| 编号 | 处理结果 |
| --- | --- |
| L-01 | 显式声明 `d3-scale@4.0.2` 和 `@types/d3-scale@4.0.9`。所有非根锁文件包条目保持原版本和内容，没有升级依赖。 |
| L-02 | 表格显示和排序都只读取自有属性；缺失的 `toString/valueOf/hasOwnProperty` 等列值显示为“—”并保持排在末尾。显示函数对非原始类型和非有限数值返回缺失标记。 |
| L-03 | 删除通用 submit 兜底，要求唯一、可见并具有发送语义或已知官方图标的控件。搜索、反馈、附件、停止、隐藏及歧义控件不被点击；负向标识（含 `data-testid`、`id`、`name`）优先否决正向标签与官方图标，祖先 `content-visibility:hidden` 也视为隐藏；受控输入更新后仍会重新识别并再次校验。 |
| L-04 | 关闭 Vite modulepreload polyfill，并为扩展页面添加 `connect-src 'none'`。实际 popup 的合成 fetch 被 CSP 阻止，测试路由保证负对照也不会访问外网。 |
| L-05 | 对所有构建 JS 执行 AST 检查，覆盖直接、成员、常量计算属性、全局对象别名等常见动态代码/网络能力入口；并覆盖计算属性与别名形式的字符串计时器、内建函数派生 receiver（含别名）的 `constructor` 动态代码路径，以及 `document.defaultView` 及其别名的全局根。内容脚本保持独立 bundle，popup 模块只能引用本地路径。 |
| L-06 | 所有展示文本拒绝双向/隐藏格式及危险控制字符，短标签禁止换行。ZWNJ/ZWJ 作为多语言拼写和 emoji 的例外保留；完整合法的 RGI 地区旗帜 tag 序列（英格兰、苏格兰、威尔士）同样保留，孤立、截断或非法的 tag 序列仍拒绝。描述和表格文本允许换行、回车与制表符。非法载荷整体保留原文，不静默剥离字符。 |

更严格的构建检查还发现原静态审计没有识别的 Zod `Function` 别名：`util.allowsEval` 探测和 `Doc.compile`。应用使用 Zod 解释器；构建时仅对这两个已知源码点做禁用处理，校验确切 SHA-256，源码有变化即失败，要求重新审查。没有修改 `node_modules`，也没有放宽 CSP。原始上游源码构成负对照，改写后的模块通过检查，编译入口实际调用会抛出禁用错误。

独立只读审查（`e9386f8..fdde16b`）在三个已提交里程碑上发现四处 Important 遗漏，并补充了简单 DOM 全局别名问题；本轮已集中修复，每项都保留先失败后通过的回归证据：冲突的停止/反馈标识可经 `data-testid` 等标识绕过发送识别；祖先 `content-visibility:hidden` 未被当作隐藏；计算属性或别名计时器、内建函数派生 receiver 的 `constructor`、`document.defaultView` 别名可逃过产物防线；完整合法的地区旗帜 tag 序列被误拒绝。修复前新增用例中 9 项（运行时 6 项、文本 3 项）与 16 项产物防线检查为刻意负对照失败，修复后转绿；另新增 2 项实际 MV3 E2E 覆盖输入后切换隐藏/Stop 与合法旗帜/孤立 tag 回退。

AST 检查是回归防线，不是任意 JavaScript 的完整安全证明；它不会把 function-plot 自有的 `eval` 回调字段误当成全局 JavaScript `eval`，也允许只读的 `Function.prototype` / `Function.toString` 内省。受限 DSUI、解释器和浏览器 CSP 继续独立生效。
