# 已知问题与后续需求

记录日期：2026-10-19（Asia/Shanghai）。以下事项先记录，尚未在本次改动中修复或实现。

## FP-001 滑块浮点精度问题

- 状态：用户反馈，待补充具体复现步骤并排查。
- 现象：滑动函数参数滑块时出现浮点精度尾数，例如 `0.1 + 0.2` 得到 `0.30000000000000004` 这类结果。
- 待确认：受影响的参数、默认值、步长和连续操作，以及尾数出现在参数值、公式、坐标显示还是原始数据中。当前记录不将某种内部原因当作已验证根因。
- 后续目标：参数按声明的十进制步长稳定变化，参数显示、公式和曲线一致；覆盖鼠标、触屏、键盘、连续增减、边界与复位，避免仅隐藏显示尾数而保留计算偏差。

## FP-002 支持任意函数图像

- 状态：后续需求，尚未实现。
- 当前限制：`function_plot` 仅接受 `quadratic` 预设，即 `y = ax² + bx + c`；`a = 0` 可退化为直线，但不能输入其他任意函数。
- 期望：未来支持任意函数图像，而不局限于二次函数。具体表达式范围、函数种类、参数方式、定义域及不连续点处理需后续设计。
- 安全约束：扩展函数能力时仍需严格校验、限定计算与绘制开销；不得执行模型提供的 JavaScript、HTML、事件或网络请求，不能用 `eval` 或 `Function` 执行表达式。

现有协议与首版范围见 [DSUI v1 协议](protocol.md#function_plot)，整体规划见本地 `docs/UI_TARGETS.md`。
