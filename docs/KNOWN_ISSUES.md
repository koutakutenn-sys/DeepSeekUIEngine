# 已知问题与后续需求

记录日期：2026-10-19（Asia/Shanghai）。保留原始反馈，并跟踪当前处理范围。

## FP-001 滑块浮点精度问题

- 状态：迁移中已改用 decimal.js 处理滑块步长、吸附和连续键盘增减；原用户反馈缺少具体操作序列，仍待用户原场景复验。
- 现象：滑动函数参数滑块时出现浮点精度尾数，例如 `0.1 + 0.2` 得到 `0.30000000000000004` 这类结果。
- 待确认：受影响的参数、默认值、步长和连续操作，以及尾数出现在参数值、公式、坐标显示还是原始数据中。当前记录不将某种内部原因当作已验证根因。
- 后续目标：参数按声明的十进制步长稳定变化，参数显示、公式和曲线一致；覆盖鼠标、触屏、键盘、连续增减、边界与复位，避免仅隐藏显示尾数而保留计算偏差。

## FP-002 支持任意函数图像

- 状态：已采用 function-plot 实现受限的显式初等函数表达式；任意函数的完整覆盖仍是后续需求。
- 当前能力：保留 `quadratic` 兼容格式，新增 `expression` 模式，支持幂、分式、根式、指数、对数、三角/反三角、双曲与绝对值函数。32 个案例已纳入数值和渲染测试，参见 [验证记录](FUNCTION_PLOT_VALIDATION.md)。
- 仍有限制：当前只支持单条显式实函数，不开放隐函数、参数曲线、极坐标或条件分段式；有限采样不能保证所有高频/病态函数的完整性。
- 安全约束：扩展函数能力时仍需严格校验、限定计算与绘制开销；不得执行模型提供的 JavaScript、HTML、事件或网络请求，不能用 `eval` 或 `Function` 执行表达式。

现有协议与首版范围见 [DSUI v1 协议](protocol.md#function_plot)，整体规划见本地 `docs/UI_TARGETS.md`。
