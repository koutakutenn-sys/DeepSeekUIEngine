# P1 富 UI 验证记录

验证日期：2026-10-20。范围为 `codex/p1-rich-ui` 开发分支；本记录不代表已发布的 v0.2 包含这些能力，也不代表已在登录后的真实 DeepSeek 会话验收。

## 实现范围

- 新增 `line_chart`、`pie_chart`（含 donut）、`scatter_chart`、`tabs`、`accordion`、`progress`、`info_card`、`comparison` 八种类型。
- 复用已经安装的 Recharts 3.10.1、React 和 Zod；原生进度条、React 按钮和 ARIA 关系实现面板。不新增依赖、权限、协议版本或远程服务。
- 保留五种原有类型。仍使用 DSUI v1、最多三个顶层区块和单 JSON 源 100,000 UTF-16 代码单元限制。
- 一条回复的所有代码块共享最多 12 个总区块、三个函数图和全局唯一的区块 ID。未访问面板也计入；超限代码块整体保留原文。
- 容器只有一层，每容器 1–6 项、每项 1–3 个叶区块；禁止容器递归、自定义动作和跨区块状态绑定。
- 折线保留 `null` 缺测断点；饼图拒绝负数、全零显示空态；散点使用真实数值坐标。三种新图表保留可展开数据表，空数据不补造样本。
- 标签页方向键、Home/End 切换并移动焦点；折叠面板 Enter/Space 展开，上下方向键、Home/End 移动焦点。首次访问的内容保留挂载，切回时保留排序和函数图参数；内容变化则按新数据重置。

具体形状、边界及示例见[协议说明](protocol.md)。

## 测试覆盖与负对照

单元测试检查严格字段、数值与数组边界、系列键一致性、重复 ID、容器初始状态、禁止递归，以及多代码块共享预算。组件测试检查数据、空态、0/72.5/100 进度、恶意标记纯文本展示、键盘导航、ARIA 对应关系和面板状态独立性。

浏览器测试加载实际构建的 MV3 扩展，在本地夹具中检查真实 SVG 的折线断点及孤立圆点、饼图和散点、原始数据、空态、浅色和深色窄屏、键盘/触屏切换、关闭面板的隐藏、状态保留、流式更新、Off 恢复原文、无效或超限代码块回退，以及嵌套函数图重开后的尺寸和滑块值。测试拦截官方域名请求，没有发送真实聊天。

负对照和修复依据：

- 新协议测试在旧五类型 schema 上出现 13 项预期失败；组件测试在旧渲染器上出现 13 项预期失败。
- 多代码块嵌套总数、嵌套重复 ID、函数图数量三项回归在修复引擎前均失败，修复后通过。
- 新 P1 浏览器检查在旧构建上出现预期失败，证明确实需要新的渲染能力。
- 截图发现折线虚线样式传到圆点，导致缺测两侧孤立点显示破碎。新增圆点实线断言先失败，再给普通和活动圆点显式设置实线，最终浏览器测试通过。
- 两次浏览器探针错误已纠正：Recharts 3.10.1 的圆点通过独立图层渲染，不能假设位于 `.recharts-line` 后代；全页状态查询包含扩展启用按钮，应限定到渲染区域。这些是测试选择器问题，不是产品构建失败，保留真实数据和断点断言。

最终测试日志保存在本地忽略的 `.cache/p1-final-{typecheck,tests,build,e2e}.log`。测试截图位于忽略的 `test-results/`，已人工检查浅色图表和深色窄屏面板；这些夹具截图不是用户聊天数据。
