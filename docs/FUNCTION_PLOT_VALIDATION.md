## 初等函数覆盖

以下 **32 个案例**均验证数值/区间回调、上游真实 SVG 渲染，以及实际 MV3 扩展中的曲线像素是否经过已知数学坐标。测试输入与期望值定义在 `tests/elementary-functions.ts`，不是根据绘图实现生成期望值。

| 类别 | 已验证表达式 |
| --- | --- |
| 常数、一次与多项式 | `x`、`3`、`x^2`、`x^3`、`x^5-2*x+1` |
| 有理函数 | `1/x`、`(x+1)/(x-1)` |
| 根式、分数幂 | `sqrt(x)`、`cbrt(x)`、`x^0.5` |
| 指数、变指数 | `exp(x)`、`2^x`、`e^x`、`x^x` |
| 对数 | `log(x)`、`ln(x)`、`log10(x)`、`log2(x)` |
| 三角 | `sin(x)`、`cos(x)`、`tan(x)` |
| 反三角 | `asin(x)`、`acos(x)`、`atan(x)` |
| 双曲 | `sinh(x)`、`cosh(x)`、`tanh(x)` |
| 绝对值与复合函数 | `abs(x)`、`sin(x)+cos(2*x)`、`exp(-x^2)`、`sqrt(x^2-1)`、`sin(pi*x)` |

补充验证：

- `sqrt(x^2-1)` 在 `(-1,1)` 内没有假连线；`1/x` 跨零处不会画成全高连线；`log(-1)` 无实数值。
- 已知坐标检查的负对照：`y=x` 不应经过 `(2,3)`。数值期望与绘图样本分开校验。
- 独立审查发现 `exp(1000)`、`sinh(1000)`、溢出乘法会被上游误画为全高竖线。先以失败回归复现，再在区间出口归一化同号无限结果；回归覆盖正/负溢出、常量与大正视口下的 `exp(x)`，确认无假曲线。
- 旧 `quadratic` 格式、开口/退化直线/水平线、参数复位、视口复位、大坐标偏移刻度继续有效。
- 鼠标、触屏与键盘滑块、十进制连续增减、滚轮、拖动、双指缩放、按钮、键盘平移、深色与 320px 窄屏通过；界面沿用现有配色与布局。
- 流式补全、追加空白保留本地状态、切换 Off、非法表达式回退原文、卸载时释放 Chart 缓存通过。
- 危险语法与超限表达式被拒绝；绘图交互和 32 个表达式测试期间未发起网络请求。

## 使用与边界

在浏览器扩展管理页重新加载项目 `dist`，再刷新 DeepSeek 页面。旧会话的已发送格式说明不会自动改写；建议新建会话后点击“启用 UI”，再要求用 `function_plot` 的 `expression` 模式绘制函数。

本记录的自动化验证使用本地官方 DOM 夹具中加载的真实扩展，没有发送真实聊天。此前隔离浏览器访问真实站点曾收到 CloudFront 403；维护者后续已确认完成人工验收，两类验证分别记录。

当前支持单条显式实函数 `y=f(x)`，不等于所有任意函数。尚未开放隐函数、参数曲线、极坐标、条件分段式或复数；最多 1,024 个采样边界点，不能保证任意高频或病态函数的完整性。负数立方根用 `cbrt(x)`；分数幂使用非负实底数。数学语法与安全上限见[协议说明](protocol.md#通用初等函数表达式)。
